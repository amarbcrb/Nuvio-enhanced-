# Nuvio Plus et Nuvio Pro

Lecteur multimédia pour Android, basé sur [Nuvio](https://github.com/NuvioMedia/NuvioMobile). Ajoute tes propres sources : l'appli les transforme en bibliothèque, avec affiches, notes, sous-titres et reprise de lecture.

## Télécharger

| Version | Accès | Lien |
|---------|-------|------|
| **Nuvio Plus** | Gratuit | [NuvioPlus.apk](https://github.com/amarbcrb/Nuvio-enhanced-/releases/latest/download/NuvioPlus.apk) |
| **Nuvio Pro** | Clé d'accès | [NuvioPro.apk](https://github.com/amarbcrb/Nuvio-enhanced-/releases/latest/download/NuvioPro.apk) |

Toutes les versions : [Releases](https://github.com/amarbcrb/Nuvio-enhanced-/releases).

Les deux applis s'installent côte à côte. Quand une nouvelle version sort, l'appli la propose en mise à jour : Nuvio Plus propose Nuvio Plus, Nuvio Pro propose Nuvio Pro.

## Nuvio Pro

Au premier lancement, Nuvio Pro demande une clé d'accès. Le code du téléphone est affiché en bas de l'écran : envoie-le au vendeur pour recevoir ta clé. Une fois activé, Nuvio Pro fonctionne exactement comme Nuvio Plus, jusqu'à la date de fin de la clé.

Pour le vendeur : création des clés et configuration dans [licence/LISEZMOI.md](licence/LISEZMOI.md).

## Développement

- Une seule branche, `main`. Chaque push construit les deux APK et publie une release.
- Différences entre les deux éditions et règles de modification : [CLAUDE.md](CLAUDE.md).
